## 🔍 Как проверить подлинность

### 📝 Пошаговая инструкция

**Шаг 1:** Скачай установщик `GoreBox_Repack_от_Пуфыстика.exe`

**Шаг 2:** Открой **CMD** (Win + R → `cmd` → Enter)

**Шаг 3:** Введи команду:

`certutil -hashfile "путь\к\GoreBox_Repack_от_Пуфыстика.exe" SHA256`

**Шаг 4:** Сверь с хешем в раздаче.

## 🛠️ Установка и запуск

### 📥 Установка

1. Запусти `GoreBox_Repack_от_Пуфыстика.exe`
2. Выбери папку для установки (по умолчанию `C:\Program Files\GoreBox`)
3. Нажми **«Установить»**
4. Дождись распаковки

> ⏳ **Важно:** Скорость установки и распаковки **зависит от мощности твоего ПК**.  
> На слабых ПК процесс может занять **дольше времени**, чем на мощных.  
> Это нормально — установщик распаковывает сжатые файлы, и чем мощнее процессор и быстрее диск, тем быстрее пройдёт установка.

### 🚀 Запуск

- После установки поставь галочку **«Запустить GoreBox»**
- Или найди ярлык на рабочем столе
- Или запусти `GoreBox.exe` из папки с игрой

### 🔐 Пароль к архиву

**Пароля нет.** Установщик распаковывается без пароля.
